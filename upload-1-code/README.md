# Felt Table

Custom 5-suit card game (Plugs, Gears, Hearts, Briefcases, Caps) plus jokers.

## Play it
Do not turn on GitHub Pages for this repo. Pages only hosts plain HTML, and this is a full app — that is why the old upload sat on "checking network."

Share the link from the app's Publish button. That is the page your friends open.

## What is in here
Source for the game: deck rules, Crazy Eights, War, and the card art in `public/cards`.
